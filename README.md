# Zimbabwe Company Financial Health & Operational Efficiency

## Project Overview

This project explores the financial health and operational efficiency of selected Zimbabwean companies using Python, SQL, and Power BI.

The analysis will use real data from official company reports and other credible sources to investigate financial performance, identify trends, and develop evidence-based business insights.

The project focuses on companies operating in Zimbabwe across consumer goods, agriculture, and industry.

## Objectives

- Assess financial performance using comparable financial indicators.
- Examine operational efficiency using relevant, publicly reported measures.
- Build a reproducible data analysis workflow using Python and SQL.
- Develop an interactive Power BI dashboard to communicate findings.
- Demonstrate practical data analytics skills through a documented GitHub portfolio project.

## Tools and Technologies

- **Python:** Data extraction, cleaning, validation, and analysis.
- **PostgreSQL:** Data storage, querying, and transformation.
- **Power BI:** Interactive dashboards and business reporting.
- **Git and GitHub:** Version control and project documentation.

## Data Sources

The project will prioritise official company annual reports, published financial statements, and other credible sources. Source documents, reporting periods, currencies, and relevant limitations will be documented to support transparency and reproducibility.

## Project Status

**Phase:** Environment setup and data-source validation.

The technical environment has been established. Company reports and available metrics will be assessed before the analytical workflow is developed.

## Important Note

Comparisons will account for differences in industries, reporting periods, currencies, and accounting bases. Metrics will only be compared where the underlying definitions and data support a meaningful comparison.
